macOS, source-built

Your recordings stay local until you choose where they go.

Journal Daemon is a forthcoming macOS agent for safely spooling recordings from configured DJI storage volumes. Its Homebrew formula compiles the command locally, there are no bottles or downloaded executables.

Install the bootstrap

Requires macOS 13+, Xcode Command Line Tools, Homebrew, and access to this repository. The formula intentionally installs from its source checkout.

brew tap guerrerocarlos/journal-daemon https://github.com/guerrerocarlos/journal-daemon
brew install --HEAD --build-from-source journal-daemon

Verify the local build:

journal-daemon version
journal-daemon config validate --config "$(brew --prefix journal-daemon)/share/journal-daemon/config.example.json"
journal-daemon doctor

What the installer does

  • Fetches this repository's current main branch through Homebrew.
  • Runs swift build --configuration release on your Mac.
  • Installs the resulting journal-daemon binary and a non-secret configuration example.

This is a bootstrap release. It proves the source-build installation and validates configuration. Connected-device discovery, the LaunchAgent, and API uploads are deliberately not enabled yet, because the first supported DJI layout and receiving API contract still need approval.

Before future service activation

Do not put API tokens in the configuration file. The planned agent will use macOS Keychain, preserve the original files on the DJI device, and retain a local spool until a server acknowledges each upload.

See the technical proposal and repository for current scope and safety constraints.
